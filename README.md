# Keep the list tidy!

This is a pretend customer list. It helps you check a change before you say yes. All the people and information are made up.

Imagine a friend wants to change something in your notebook. This app asks you first!

## Open it

Ask a grown-up to help with the first setup. You need a computer with Python 3 installed. This does not run inside the GitHub page.

1. At the top of this GitHub page, click the green **Code** button.
2. Click **Download ZIP**.
3. Open the downloaded ZIP, then open the folder inside it.
4. On a Mac, double-click **Start Demo.command**. On Windows, double-click **Start Demo.bat**.
5. A page opens in your browser. Your practice list is ready!

Keep the little terminal window open while you use the page. If the page does not open, copy the link shown in that window into your browser.

If the start file does not open, ask a grown-up to open a terminal in the project folder and run:

```bash
python3 start_demo.py
```

On Windows, use `py -3 start_demo.py`. If Python is missing, get it from [python.org](https://www.python.org/downloads/).

## Try it: say yes or no

1. Find **Changes waiting for you**. There are two changes to try.
2. Look at **Now** and **Suggested change**. What would change?
3. Click **Yes, change it** to use the new value. Or click **No, keep it** to keep the old value.
4. Look at **Our pretend list** to see the result.
5. Look at **What happened** to see the history.

You cannot break a real customer list here. This is only practice.

## Stop or start again

Click the terminal window and press **Control+C** to stop. Close the browser tab when you are done.

Open the start file again to get a fresh practice list. Practice changes disappear when you stop; each new session starts over.

## Big words, small meanings

| Word | What it means |
|---|---|
| CRM | A notebook for customer information. |
| Record | One item in the list. |
| Stage | Where the work is right now. |
| Next step | What to do next. |
| Approve | Say yes to a change. |
| Reject | Say no to a change. |
| Audit log | A list of what happened. |
| Data integrity | Keeping information correct. |
